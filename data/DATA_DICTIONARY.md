# Data dictionary

All data are **synthetic**, generated by `src/run_experiments.py` with a fixed
seed (`SEED = 20260628`). No real brand or personal data are included.

## `synthetic_brand_field.csv`

A synthetic brand field of 100 observations across four source types. Each row
is one observed brand state `P_o` (a probability distribution over six semantic
dimensions) together with its distances to the ideal distribution `P*`.

| Column | Type | Description |
|---|---|---|
| `observation_id` | string | Unique id, `<source>_<nn>`. |
| `source` | string | Source type: `institutional`, `campaign`, `reviews`, or `lifestyle`. |
| `durability` | float | Probability mass on the *durability* dimension (core). |
| `environmental_stewardship` | float | Mass on *environmental stewardship* (core). |
| `repairability` | float | Mass on *repairability* (core). |
| `functional_competence` | float | Mass on *functional competence* (core). |
| `style_aesthetics` | float | Mass on *style / aesthetics* (peripheral). |
| `status_luxury` | float | Mass on *status / luxury* (peripheral). |
| `kl_to_ideal` | float | `D_KL(P_o ‖ P*)` in nats. |
| `js_to_ideal` | float | Jensen–Shannon divergence to `P*` in nats. |
| `fisher_rao_to_ideal` | float | Fisher–Rao geodesic distance to `P*`. |
| `coherence` | float | `C(o) = -D_KL(P_o ‖ P*)`. |

The six probability columns sum to 1 (up to floating-point tolerance) for each row.

## `ideal_distribution.json`

The ideal distribution `P*` as a JSON object mapping each of the six semantic
dimensions to its probability mass. `P*` concentrates mass on the mission-led
core (durability, environmental stewardship, repairability, functional
competence).

## `results_summary.json`

Headline quantities from the three experiments (seed, monotonicity flags,
core/peripheral cost ratio, geodesic vs. Euclidean path lengths and deviation,
natural-gradient convergence). Regenerated on every run.
